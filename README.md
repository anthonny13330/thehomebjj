# The Home BJJ

Site estático da academia (HTML + CSS + JS, sem dependências). Abre `index.html` ou serve a pasta em qualquer alojamento.

## Personalizar
- **Dados e horários:** topo de `js/main.js` (`CONFIG` e `SCHEDULE`). Os valores atuais são exemplos.
- **Fotos:** coloca ficheiros em `images/` com os nomes usados no `index.html` (`hero.jpg`, `hero-house.jpg`, `about-1.jpg`, `about-2.jpg`, `class-*.jpg`, `coach-1..3.jpg`, `gallery-1..6.jpg`). Enquanto faltarem, aparece um espaço reservado.
- **Logótipo:** animação H → casa definida em `js/main.js` (`LOGO`) e `css/styles.css` (secção LOGO).
